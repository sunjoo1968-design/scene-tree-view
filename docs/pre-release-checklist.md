# SceneAnchor Pre-Release Checklist

이 체크리스트는 실제 방송 안정성을 우선으로 한다. 테스트는 가능하면 OBS Studio 32.0.2와 최신 OBS 32 계열에서 각각 수행한다.

## 빌드 확인

- Windows x64 빌드가 성공한다.
- `test_tree_store`가 성공한다.
- locale 검사에서 누락 키, 미사용 키, placeholder 불일치가 없다.
- 설치 패키지 또는 수동 설치 레이아웃에 삭제된 locale 파일이 포함되지 않는다.

## UI 확인

- dock 상단에 검색창만 있고 최근 장면 빠른 버튼 줄이 없다.
- dock 하단에는 폴더 추가 버튼과 폴더 제거 버튼만 있다.
- 장면을 선택한 상태에서 하단 제거 버튼을 눌러도 OBS 장면이 삭제되지 않는다.
- 빈 영역 우클릭 메뉴에 장면 추가 항목이 없다.
- 빈 영역 우클릭 메뉴에 최근 장면 표시 옵션이 없다.
- 장면 우클릭 메뉴에는 전환과 색상 라벨만 있다.
- 폴더 우클릭 메뉴에는 하위 폴더 추가, 이름 변경, dissolve, 폴더 제거, 색상 라벨만 있다.

## 트리 이동 확인

- 폴더를 루트와 다른 폴더 사이로 이동할 수 있다.
- 장면을 폴더 안으로 이동할 수 있다.
- 장면을 폴더 밖의 루트 위치로 이동할 수 있다.
- 아직 SceneAnchor에 배치되지 않은 장면을 원하는 위치로 drag-and-drop하면 이후 SceneAnchor 저장 순서가 유지된다.
- 여러 장면과 폴더를 함께 선택해 이동해도 문서 순서가 유지된다.
- 검색 필터가 켜진 동안 drag-and-drop이 동작하지 않는다.

## OBS 안정성 확인

- SceneAnchor에서 장면을 이동해도 OBS 기본 장면 dock의 순서가 바뀌지 않는다.
- SceneAnchor에서 폴더를 제거해도 OBS 장면 자체는 남아 있다.
- SceneAnchor UI 안에는 장면 추가, 장면 삭제, 장면 복제, 장면 이름 변경 진입점이 없다.
- 장면 전환은 명시적인 선택 전환, 더블클릭 전환, 우클릭 전환에서만 발생한다.
- OBS scene collection 저장/로드 후 폴더 구조와 장면 배치가 유지된다.
- scene collection 복제 또는 이름 변경 후 가능한 한 저장된 장면 이름 fallback으로 트리가 복구된다.

## 수동 방송 리허설

- 실제 방송용 scene collection 사본으로 테스트한다.
- 방송 송출 중에는 먼저 짧은 비공개/녹화 리허설에서 장면 전환, 검색, 폴더 이동만 검증한다.
- crash log, OBS log, scene collection JSON을 함께 보관한다.
- 문제가 발생하면 SceneAnchor dock을 닫고 OBS 기본 장면 dock만으로 진행 가능한지 확인한다.
