# Scene Tree View 1.0.11

방송 안정성 순차 점검의 1차 수정본입니다. 전체 소스 점검은 아직 진행 중입니다.

- 대량 장면 이동과 폴더 해제 시 범위 삽입으로 불필요한 반복 처리를 줄였습니다.
- OBS 캔버스 조회 실패 시 초기화로 기존 배치가 삭제되지 않도록 보호했습니다.
- 1만 항목 이동·폴더 해제 및 혼합 선택 회귀 테스트를 추가했습니다.

전체 저장소 회귀 테스트, Windows x64 빌드, ZIP의 DLL 해시 검증을 통과했습니다. 실제 OBS UI·장시간 방송 테스트는 미실시입니다.

OBS 종료 후 ZIP의 `data`, `obs-plugins`를 OBS 설치 폴더에 병합하세요. OBS 본체와 다른 플러그인은 포함하지 않습니다. 내부 DLL 이름 `scene-anchor.dll`은 호환성을 위해 유지합니다.
