# Scene Tree View 1.0.10

장면 트리-Made by Sunjoo

## 1.0.7 이후 변경사항

- 다중 선택 이동, 위·아래 배치 이동, 확인창을 갖춘 배치 초기화.
- OBS 원본 이름과 독립적인 장면 별칭 변경 및 이름 복사.
- 폴더·장면 아이콘 색상 일괄 변경과 새 폴더 자동 번호.
- 폴더 삭제 아이콘, DEL 키 및 우클릭 메뉴의 통합 확인창.
- 폴더만 해제하거나 하위 배치까지 삭제하는 선택 기능. 실제 OBS 장면은 삭제하지 않습니다.
- 접힌 폴더의 송출 상태 표시 및 장면 전환 없는 현재 송출 장면 찾기.
- 폴더 배치 JSON 백업·복원. 같은 OBS 장면 모음에서만 복원하며 배치 잠금과 파일 검증을 적용합니다.

## 설치

Windows x64 / OBS 32 계열용 플러그인 ZIP입니다. OBS를 완전히 종료하고 ZIP의 `data`, `obs-plugins` 폴더를 OBS 설치 폴더(일반적으로 `C:\Program Files\obs-studio`)에 병합하세요.

기존 호환성을 위해 DLL 이름은 `scene-anchor.dll`입니다. OBS 본체나 다른 플러그인은 포함하지 않습니다.

## 검증 및 주의

Windows 빌드, 저장소 회귀 테스트, 로케일 검사 및 ZIP의 DLL 해시 검증을 통과했습니다. 실제 OBS 마우스 조작과 장시간 방송 테스트는 미실시이므로 방송 전 오프라인 테스트를 권장합니다.

배치 백업은 OBS 장면·소스 자체를 저장하지 않습니다. OBS 장면 모음 백업도 별도로 보관하세요.
