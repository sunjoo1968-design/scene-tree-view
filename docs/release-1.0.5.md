# SceneAnchor 1.0.5

## Plan

방송 운영 중 배치 변경과 의도하지 않은 전환을 방지한다. 기본 OBS 동작은 변경하지 않는다.

## Do

- 하단 배치 잠금: 설정 저장, 드래그 및 폴더 편집 차단. 폴더 펼치기와 장면 선택은 유지.
- 더블클릭 처리와 우클릭 전환 메뉴 및 이전 더블클릭 설정 API 제거.
- 검색 Enter는 일반 장면 선택으로 통일. 스튜디오 모드의 프로그램 전환 호출 제거.
- 우클릭으로 장면 선택이 바뀌지 않도록 처리.
- 트리 갱신 시 메뉴 종료, 색상 대화상자의 오래된 트리 경로 사용 차단.
- OBS 캔버스와 설정 포인터의 null 방어 추가.

## Check

빌드, 저장소 회귀 테스트, 로케일 검사, ZIP 경로와 DLL 일치를 확인한다.
실제 OBS에서의 마우스 조작 및 장시간 방송 검증은 별도 수행이 필요하다.

## Act

플러그인 전용 ZIP으로 제공한다. OBS 종료 후 data 및 obs-plugins 폴더를 설치 루트에 병합한다.
더블클릭의 첫 클릭은 기존 단일 클릭 선택이다. 일반 모드에서는 OBS의 일반 선택 동작에 따라 송출 장면이 바뀐다.
스튜디오 모드에서는 선택이 미리보기에만 적용되며, SceneAnchor는 프로그램 전환을 실행하지 않는다.
